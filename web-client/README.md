# stitch-web-client

Phase 1 skeleton for web runtime.

## Scripts
- `bun run dev`
- `bun run build`
- `bun run typecheck`
- `bun run lint`

## Env
- `VITE_SPACETIME_URI` (default: `ws://127.0.0.1:3000`)
- `VITE_SPACETIME_MODULE` (default: `stitch-server`)
- `VITE_LOG_LEVEL` (default: `info`)
- `VITE_TOKEN_STORAGE_KEY` (default: `stitch-web-token`)
