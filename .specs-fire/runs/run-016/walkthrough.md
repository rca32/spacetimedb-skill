## Key Implementation Details

### 1. Repeatable multi-identity style harness
`--repeat`와 deterministic run tag를 사용해 동일 시퀀스를 N회 재실행 가능하게 구성했다.

### 2. Security regressions as expected-fail checks
권한 상승/세션 하이재킹/private table 조회를 expected-fail로 명시해 실패 조건을 회귀 기준으로 고정했다.

### 3. Load probes with lightweight loops
이동 burst와 agent loop fan-out을 결합해 AOI/스케줄러 경로를 빠르게 반복 점검하도록 구성했다.
