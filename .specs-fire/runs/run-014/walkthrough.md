## Key Implementation Details

### 1. Role-Based Access Control
`role_binding` 기반으로 admin 전용 작업(역할 관리)과 운영자 작업(신고 검토/제재)을 분리했다.

### 2. Report Pipeline
`report_submit`이 신고를 큐에 적재하고, `report_review`가 유효 판정 시 moderation score와 action 이력을 남긴다.

### 3. Moderation Actions
`moderation_apply_action`은 `warn/ban/unban` 액션을 지원하며 `moderation_flag`와 `ban_list`를 동기 갱신한다.

### 4. Audit and Rate Limit
모든 민감 reducer에서 공통 helper를 통해 `audit_log`를 기록하고 `rate_limit_bucket`으로 호출 폭주를 제한한다.
