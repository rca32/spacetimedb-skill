# Implementation Walkthrough: 소셜 채팅/파티/길드 코어 루프 구현

## Summary
소셜 도메인에 채팅/파티/길드 코어 리듀서를 추가하고, `social_feed` 기록 및 구독 SQL helper를 연결했다.

## Structure Overview

## Key Implementation Details

### 1. Chat Core Loop
`chat_send_message` reducer에서 `chat_channel` 존재 여부와 채널 타입별 접근 권한(일반/리전/파티/길드)을 검증한 뒤, `rate_limit_bucket` 기반 윈도우 제한을 통과한 요청만 `chat_message`에 기록한다.

### 2. Party Lifecycle
파티 생성/가입/탈퇴/리더 위임 reducer를 분리하고, 멤버 키(`party_id:identity`) 기준으로 일관된 membership 관리와 리더 권한 전이를 처리한다.

### 3. Guild Lifecycle + Project
길드 생성/가입/역할 변경/프로젝트 진행을 분리 구현했다. 역할 변경은 리더 전용으로 제한하고, 프로젝트 업데이트는 오피서 이상 권한만 허용한다.

### 4. Social Feed and Subscription Paths
각 이벤트 지점에서 `social_feed`를 append해 활동 로그를 남기고, `social_stream`에서 채팅/파티/길드/피드 조회 query를 제공한다.
