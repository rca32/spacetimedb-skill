## 4) 실행 로그 이슈 정리
### 관찰 로그
- 연결 로그:
  - `client_connected returned Ok for unknown ip ...`
  - `Database accepted connection from unknown ip ...`
- 에러 로그 (반복):
  - `2026-02-10T14:26:57.368471Z` 이후 다수
  - `reducer returned error: request_id must be <= 64 chars`

### 분석
- 원인 후보가 아닌 항목:
  - `unknown ip` 연결 메시지는 로컬/개발 환경에서 관찰 가능한 일반 연결 수락 로그이며 치명 오류로 분류하지 않음.
- 실제 원인:
  - `stitch-client/src/plugins/sync.rs`에서 `move_to` 요청 ID를 아래 형태로 생성:
    - `format!("mv:{identity:?}:{}", prediction.request_counter)`
  - 서버는 `stitch-server/crates/game_server/src/validation/anti_cheat.rs`에서 `request_id <= 64`를 강제.
  - `identity` 디버그 문자열 길이에 따라 요청 ID가 64자를 초과해 `move_to` reducer가 거절됨.

### 영향
- 이동 요청 일부/대부분이 서버에서 거절될 수 있어,
  - authoritative 이동 반영이 지연/누락되고
  - 보정 루프와 체감 이동 안정성이 저하될 수 있음.
