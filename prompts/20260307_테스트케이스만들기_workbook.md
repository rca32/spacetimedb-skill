# 20260307_테스트케이스만들기 workbook

- 서버 진실 소스: `stitch-server/crates/game_server`의 `#[spacetimedb::table(accessor = ...)]`, `#[spacetimedb::reducer]`
- 재생성 명령은 기본적으로 `stitch-server/target/.../game_server.wasm` 기준 `spacetime generate --bin-path ...`를 사용.
- `--module-path` 직접 생성은 현재 로컬 rust target 부재 시 실패할 수 있으므로 보조 경로로 유지.
- 생성 결과 확인:
  - public table accessor는 `physics_state`, `server_correction`, `combat_hit`, `aoi_stream`, `ui_notification_event`
  - reducer accessor는 client 측에서 `syncClientFrame`, `submitMotionIntent` 같은 camelCase
- Babylon client 런타임 이슈:
  - query text는 server SQL table 이름을 사용해야 함
  - `connection.db` accessor도 generated accessor 그대로 `snake_case`를 사용해야 함
- 서버 회귀 시나리오:
  - 정상 motion intent
  - correction + ack
  - build preview valid/invalid
  - combat event fanout
  - npc talk log
