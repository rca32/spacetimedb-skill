### 2) PBRLit WebGPU 오류 대응
- 증상:
  - `TextureSampleType::Depth` vs `SamplerBindingType::Filtering`
  - `Invalid RenderPipeline "pbrlitshader|pbrlitshader"`
- 대응:
  - 메시/스킨드메시 렌더러의 모든 `materials[]` 순회
  - 각 머티리얼에 `acceptShadow=false`, `castShadow=false`
  - `setDefine('USE_SHADOWMAPING', false)` 강제
  - 인스턴스 생성 직후에도 재적용
  - 런타임 전역 가드(주기 스캔) 추가
- 반영 파일:
  - `stitch-orillusion-client/src/world/world-scene.ts`
  - `stitch-orillusion-client/src/world/stream-visualizer.ts`
  - `stitch-orillusion-client/src/app/runtime.ts`

### 3) 겹침 오브젝트/박스 제거
- 로컬 플레이어 스트림 마커 제거
- 플레이어 fallback 박스 제거
- `aoiStreamV2` 디버그 큐브 렌더 비활성화
- 빌드 모드 기본값 OFF (`buildModeEnabled = false`)
- 이동 먼지(`movement-dust`) FX 비활성화
- 반영 파일:
  - `stitch-orillusion-client/src/world/stream-visualizer.ts`

### 11) resource(나무) 렌더 성능 최적화 1차
- 배경:
  - 나무 개체 수 증가 구간에서 프레임 하락 체감
  - 기존 경로는 `resourceNode`를 프레임마다 전수 순회하며 개별 오브젝트 갱신
- 적용:
  - `WorldStreamVisualizer`에 리소스 전용 인스턴싱 루트 추가
  - `InstanceDrawComponent` 부착 기반으로 resource 렌더 경로를 `instanced|legacy` 모드로 운영
  - 인스턴싱 초기화 실패 시 자동으로 `legacy` fallback
  - `resourceNode` 동기화 간격 제한(`RESOURCE_SYNC_INTERVAL_MS = 120`)
    - 프레임마다 전수 순회하지 않고 저주기 갱신으로 CPU 비용 완화
  - HUD에 디버그 정보 추가:
    - `resource render mode`
    - `resource sync interval`
- 환경변수/운영 토글:
  - `VITE_RESOURCE_INSTANCING`
    - 기본 `1`(인스턴싱 사용)
    - `0`으로 즉시 우회 가능(legacy 경로 강제)
- 반영 파일:
  - `stitch-orillusion-client/src/world/stream-visualizer.ts`
  - `stitch-orillusion-client/src/infra/config.ts`
  - `stitch-orillusion-client/src/app/runtime.ts`
  - `AGENTS.md`
- 검증:
  - `cd stitch-orillusion-client && bun run typecheck` 통과
  - `cd stitch-orillusion-client && bun run build` 통과
- 체감 결과:
  - 사용자 기준 프레임 개선 체감 확인됨
- 다음 최적화 때 바로 볼 체크포인트:
  - `RESOURCE_SYNC_INTERVAL_MS`를 `120 -> 150 -> 200` 비교 후 고정값 결정
  - `VITE_RESOURCE_INSTANCING=0/1` 비교로 인스턴싱 순수 효과 분리 측정
  - 다음 병목 후보: `terrain/water` 경로 프로파일링
