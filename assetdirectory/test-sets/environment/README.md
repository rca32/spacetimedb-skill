# Environment Test Set (assetdirectory)

총 50개 GLB를 바로 실험에 쓰기 쉬운 형태로 분류한 테스트셋입니다.

- `buildings/` : 건물/요새/모듈류
- `structures/` : 도시 빌딩 계열
- `modules/` : 던전 계열
- `nature/` : 자연 소품/지형 보조물
- `rocks/` : 바위/절벽/돌 오브젝트
- `walls/` : 벽, 문, 계단, 문형 장식, 가드레일

원본은 `pack/kenney/*` 하위이며, 매핑은 `audio_refs/testset_index.csv`를 참조하세요.
