A physics component for [Orillusion](https://www.orillusion.com), powered by [Ammo.js](https://github.com/kripken/ammo.js/)

## Usage
```bash
npm install /core --save
npm install /physics --save
```
```ts
import { Scene3D } from "@engine/core"
import { Physics } from "@engine/physics"
```

Or access Global build from CDN
```html
<script src="https://unpkg.com//core/dist/orillusion.umd.js"></script>
<script src="https://unpkg.com//physics/dist/physics.umd.js"></script>
```
