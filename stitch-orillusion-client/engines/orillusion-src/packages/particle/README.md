A particle system for [Orillusion](https://www.orillusion.com)

## Usage
```bash
npm install /core --save
npm install /particle --save
```
```ts
import { Scene3D } from "@engine/core"
import { ParticleSysteam } from "@engine/particle"
```

Or access Global build from CDN
```html
<script src="https://unpkg.com//core/dist/orillusion.umd.js"></script>
<script src="https://unpkg.com//particle/dist/particle.umd.js"></script>
```

More doc from [Orillusion](https://www.orillusion.com/guide/particle/Readme.html)
