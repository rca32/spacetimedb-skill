Extra geometry plugins for [Orillusion](https://www.orillusion.com)

## Usage
```bash
npm install /core --save
npm install /geometry --save
```
```ts
import { Scene3D } from "@engine/core"
import { TextGeometry, ExtrudeGeometry, TerrainGeometry } from "@engine/geometry"
```

Or access Global build from CDN
```html
<script src="https://unpkg.com//core/dist/orillusion.umd.js"></script>
<script src="https://unpkg.com//geometry/dist/geometry.umd.js"></script>
```

More doc from [Orillusion](https://www.orillusion.com/guide/graphics/mesh.html)
